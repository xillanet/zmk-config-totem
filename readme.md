# ZMK CONFIG FOR THE ONE-HANDED KEYBOARD USING TOTEM

[Here](https://github.com/GEIGEIGEIST/totem) you can find the hardware files and build guide.\
[Here](https://github.com/GEIGEIGEIST/qmk-config-totem) you can find the QMK config for the TOTEM.

Original TOTEM is a 38 key column-staggered split keyboard. This fork is using ZMK TOTEM and is design for one-handed use and is specifically for Japanese.

本フォークは無線分割キーボード「TOTEM」の左手側（または右手側）を使い、開発中の「SEKI配列」を実証試験するためのレポジトリになります。

SEKI配列は片手だけで一通りのキー入力が可能になることを目指しています。
左右どちらでも使えますが、右利きを想定し、利き手がフリーになるよう、左手側を優先して調整しています。

SEKI配列の基本コンセプトとして、完全に日本語の入力に特化しています。
英語やプログラミングには不向きですが、その分、日本語入力は効率的になるようにデザインされています。
レイヤーを使っていますが、日本語の清音はレイヤー切り替えなしで入力可能です。濁音は清音キーのレイヤー切り替えに配置されています。
4つのレイヤーを使うことで、ほぼすべての英数字と記号の入力が可能です。

また、指を主体としたタッチタイピングを重視しています。
普通のキーボードは掌底を卓上やパームレストに置いたあと、打鍵したいキーの位置によって掌底を軸に手を回転させたり、場合によっては掌底を浮かせてい手を奥や左右に移動させているケースが多いかと思います。
しかしTOTEMは掌底の位置を固定し、ほとんど回転させることもなく、指の動きだけで全キーを入力します。そのため、キー数が少なく、キーピッチもChocの狭ピッチを採用しています。SEKI配列もこの考え方を受け継ぎ、掌底を固定して指の動きだけで文字入力することに強く志向しています。

## 本フォークの特徴
- **片手入力最適化配列** ：TOTEMの片側（19キー）だけでほぼ一通りのキー入力を可能としている。
- **日本語特化配列**：日本語だけならばレイヤー切り替えが最小となるようにデザイン。
  - 濁音は対応する清音のレイヤー切り替えに配置。サブレイヤーは覚えやすさ重視。
  - 母音は中指と薬指に集中配置。同じ指が連続して異なるキーを叩かないように配慮。
  - 頻度の高い「OU」「AI」などは中指・薬指がスムーズに入力できるように意識して配置。
  - 人差し指は可動範囲が大きく、器用な人が多いので子音を多めに配置。
- **4レイヤー構成** ：レイヤーは、baseが基本。親指キーのホールドでnav、num、subと切り替える。
  - base_layerは母音と子音の清音。
  - nav_layerは親指左キーのホールド。カーソルや修飾キー、Bluetooth設定キーを配置。
  - sub_layerは親指右キーのホールド。濁音や読点、あとは日本語入力であまり使わない文字。
  - num_layerは親指中央キーのホールド。数字キーは電話由来の123が上になる配列。各種記号キーも左右に配置。
- **英語キーボード設定向け** ：英語キーボード（US配列）として設計。
  - Shiftキーによる記号などの対応は英語キーボード準拠なので注意。とくに数字キー。
  - US配列として認識されればいいので、ペアリング時のトラブルが起きにくいハズ。
  - 言語切替のLANG1キーとLANG2キーがあるので、アップル製品とAndroidでは日本語・英語の切り替えが容易（Windowsは未検証）。
- **ホールドタップ不使用** ：GUI/ALT/CTRLキーはSticky Keyを使用。Shiftはホールド設定で単押しは言語切替。
- **2026年6月時点のビルドで安定動作** ：ビルドエラーを回避するためにZMKのバージョンを`v0.2`に固定。

## 備忘録：用途の想定・実機利用の感想
- スマートフォンやタブレット、空間コンピュータデバイスなどでの利用を想定。
  - フルキーボードの効率には及ばないので、パソコンで使う意味は少ない。
  - スマートフォンのフリック入力よりは高速なので長文入力ではかなり実用的。
- 寝転びながらや立ったまま、安楽椅子、高速バス車内など、フルキーボードで対応しにくい環境でも利用しやすい。
- 右手でキーボードを持って左手で打鍵する逆トニー谷スタイルもかろうじて可能。ウェアラブルもできるかも。
- TOTEMの片手だけだと可搬性が高く、設置面積も小さいので、使える場面が大幅に増える。
  - 定食屋で定食が出てくるまでの時間にスマホで長文が書ける。
  - 定食屋の狭い卓上スペースでも定食の載ったお盆と共存できる。
  - ポケットに入る大きさなので、とっさに取り出したりしまったりしやすい。
- 右手に何かを持ったりし作業しながらの文字入力にも向いている。
  - 右手でマウスやタッチ操作、ジェスチャをするのが基本か。
  - 右手で別デバイスを使えるので、機器レビュー時などのメモ取りにも便利。
  - 右手でポテチを食べててもキーボードが汚れない。
- 数日で配列は頭に入る。数週間で不便を感じない速度になる。
  - しかし小指がけっこう疲れる印象はある。
  - 右手で完全に別の作業をしながらの入力は脳のキャパ的に難しい。

## 備忘録：ハードウェアの調達
- TOTEMはAliExpressで1〜2万円でハンダ済みのTOTEM完成品を購入できる。
  - Choc V1のみとChoc V1/V2両対応版があるので注意。
  - XIAO BLEのものが主流と思われるが、有線版もあるのかも（本レポジトリは無線対応）。
  - XIAO BLEはモジュール自体が日本の技適を取得している。
  - 当然だが両手を買っても使うのは片手だけでコスパは最悪。
  - Choc V2対応改修版にPurple Glede軸をつけて買ったけど、癖になるキータッチ。
  - KLP Lameキーキャップとの相性抜群なのでセット品もオススメ。
- 既製品を買うとコストがかさむので、片手だけ低コストに生産できるオリジナル20キーキーボードの製造を計画中。

## 備忘録：やったこと
- Gemini師匠にアドバイスを求めながらビルドエラーを解消。バージョンv2.0にしたのが決め手な模様。
- 右手は独立動作するように書き換え済み。右手は子機として左手に接続できない。

## 備忘録：キー配列のカスタマイズ
- レポジトリをフォークする。
- [キーマップエディタ](https://nickcoutsos.github.io/keymap-editor/)に自分のレポジトリを読み込ませる。
- カスタマイズしたらSaveすると、レポジトリ側に反映され、設定しておけば自動ビルド。

## 備忘録：ファームウェアの書き込み方法
- ファームウェアをビルドしてダウンロードする。
- TOTEMの電源を切り、USBケーブルでPCに接続する。
- 側面のボタンスイッチを2連打する。
- PCにドライブがマウントされるので、そこにビルドしたファームウェア（.uf2）をコピーする。
- コピーが終わると強制アンマウントされるが、ファームウェアは書き換わる。
